# Stack icon sources

- Devicon original variants for the development and infrastructure logos. The AWS dark variant uses white lettering. [Source revision](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons) · [MIT license](LICENSE-DEVICON.txt)
- Microsoft Fabric and Power BI use the 48-pixel color SVGs from the Microsoft Fabric icon collection. [Source archive](https://github.com/microsoft/fabric-samples/blob/564ec4139742b838468fcf8aa44dac4afe02ce92/docs-samples/Icons.zip) · [Microsoft icon terms](https://learn.microsoft.com/en-us/fabric/fundamentals/icons#terms)
- Simple Icons glyphs for Chromatic, Coolify, Cursor, GitHub, GitHub Copilot, Next.js, Resend, and Sentry. Local fill colors provide contrast on light and dark backgrounds. [Source revision](https://github.com/simple-icons/simple-icons/tree/17cd4ee07612198a1d8777a060d4100423762a8b/icons) · [CC0 license](LICENSE-SIMPLE-ICONS.txt)
- Codex and OpenAI use the matching Lobe Icons SVGs. The OpenAI mark uses black and white variants for light and dark mode. [Source revision](https://github.com/lobehub/lobe-icons/tree/9752d967494e48d8f83f2808feb2b0207bf70997/packages/static-svg/icons) · [MIT license](LICENSE-LOBE-ICONS.txt) · [OpenAI brand guidelines](https://openai.com/brand/)
- Neon uses the color logomark with its supplied clear space. [Neon brand assets](https://neon.com/brand)
- Doppler uses the SVG site icon. [Doppler](https://www.doppler.com/) · [Source SVG](https://cdn.sanity.io/images/q3zajrd2/production/01ad0eb786c8260c4daa709fe8a6f57fb063655e-101x100.svg)
